# Completed TCP optimization records

These records document the completed TCP lifecycle and transfer optimization
batch. They are intentionally nested because the optimization notes use the
numeric prefixes 126–133, while canonical `AGENT/tasks/index.tsv` already uses
task 126 for the explicit `std/unsafe` boundary. The canonical index remains
unique and tracks the numbered implementation tasks; this directory preserves
the optimization-specific symbols, evidence, and acceptance notes.
